ISPSS — what's new

ISPSS is the shared services layer underneath every Idira product. This page tracks recent, notable additions — check the official docs for the authoritative, dated changelog.

01Recent additions

  • CORA AI

    Session summaries for SIA

    CORA AI now produces textual summaries of recorded SSH sessions, and textual audits of recorded RDP sessions, performed through Secure Infrastructure Access — cutting down the time spent manually reviewing recordings.

  • CORA AI

    AI-assisted account onboarding

    Discovered accounts can now be onboarded using AI-based recommendations from the Remediation agent, rather than working through each one manually.

  • CORA AI

    Knowledge Base as a source

    The CORA AI chatbot now draws answers from CyberArk's Knowledge Base articles in addition to official product documentation, giving broader troubleshooting and configuration guidance directly in chat.

  • Naming

    Chatbot renamed to "assistant"

    What was previously called the CORA AI chatbot is now referred to as the CORA AI assistant across the platform and its documentation.

  • Connectivity

    Microsoft Entra cloud onboarding

    Microsoft Entra tenants can now be onboarded using CyberArk's cloud onboarding capability, which automatically migrates targets to Azure Federated Identity for a more seamless and secure authentication flow.

  • MCP / Agents

    Custom remote MCP server registration

    Organizations can now register custom remote MCP servers and keep an MCP server's OAuth app in CyberArk connection mode, so that agent-and-user identity is captured in audit trails even when CyberArk isn't the authorization service by default.

  • Permissions

    Updated connection permissions

    The connection artifacts and permissions Idira needs to discover and secure resources have been updated — worth reviewing if you maintain custom integration scopes.

Keep this current Platform release notes move fast and this page is a snapshot, not a live feed. For the authoritative, continuously updated list, check the official Idira documentation's "What's New" section directly.
